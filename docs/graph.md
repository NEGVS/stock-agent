最重要的三个结论
如果你今天只记住三件事，那就是：
1. State 是共享数据，不是普通参数。
每个节点都围绕同一个 State 工作，节点之间通过它传递信息，而不是互相直接调用。
2. Node 就是一个遵循统一协议的函数。
它接收 State，处理后返回 State。这样 Graph 可以自由调度任何节点。
3. Graph 本身不负责业务逻辑，它只负责调度。
真正的分析、新闻获取、技术指标计算、风险评估，都应该放在各自的 Node 中。
